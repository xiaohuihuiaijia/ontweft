## 2026-11-10：预览并确认批量关系

新增基于已发布关系、两侧可读标量字段的批量匹配。先预览完整分类计数及样本，用户确认后才创建真实关系；存在未解决记录时默认拒绝，必须明确选择才能只执行唯一匹配。保留已有关系，检查单目标基数，不猜测重复目标，不默认允许自引用。

执行时在写事务内重新核对权限、模型版本、对象修订、匹配值和已有关系。SQLite 使用写锁，PostgreSQL 使用项目行锁；手工创建/删除关系遵循同一串行化边界。审计保留规则与实际写入两端的对象修订。它是一次性关联，不持续重连，不提供跨来源身份合并。

前端 152 项通过，构建通过。对象与来源回归 137 项通过、32 项因环境未配置跳过；此后补充的自引用/旧版本用例纳入关系专项，专项最终 10 项通过、2 项 PostgreSQL 条件跳过。独立 PostgreSQL 17.9 与 SQLite 的模板/上传/关系联合专项 37 项通过，包含手工写入与批量匹配争夺同一单目标关系的并发验证；临时容器已清理。各组范围有重叠，不累加。

真实 Chromium 在隔离库与 worker 中完成上传两个对象、编辑和发布关系模型、创建一个合成目标、预览一条可匹配与一条未解决记录、明确选择部分执行、建立一条实际关系。图谱显示三个节点、一条边；刷新后保留，1440/375/320px 无横向溢出且没有页面异常。测试进程与临时数据已清理，截图仅含合成数据。本批远端检查须以其对应提交为准。

## 2026-11-10：本机入口连接真实数据库

本机服务与 worker 新增重复的 `--source-host` 参数以及独立的 `--allow-private-sources` 选项。默认仍无网络来源权限；主机名单拒绝通配符、带凭据 URL、端口和路径，内网地址需要额外明确开启。账号密码在连接表单中单独填写，既有工作空间可保留后重启，不读取开发环境配置。

本机入口专项 10 项通过，覆盖默认隔离、明确主机、内网地址的独立放行与输入错误。独立 PostgreSQL 17.9 专项 10 项通过：其中 2 项分别在 SQLite 和真实 PostgreSQL 应用存储上，用真实只读 PostgreSQL 来源完成连接/发现、多表建模、模型发布、快照对象、精确匹配关系和二次更新；其余 8 项为已有模板合同。验证了整数、超 JavaScript 安全范围的十进制、日期、布尔、JSON、数组、UUID、带时区及无时区时间，未借用开发凭据，测试容器已清理。

数据库更新保留同一对象身份和人工备注；只读账号的写入尝试被拒绝。这个结果不外推为 MySQL、飞书或生产网络验收，也不是 PostgreSQL 运行账户全部合同的全量验证。

关系问题记录已增加分页，所有未解决项均可查看；翻页检查原预览摘要，数据变化或字段权限撤回时拒绝继续读取。关系后端专项 11 项通过、2 项 PostgreSQL 条件跳过，前端关系专项 3 项通过，构建通过。

关系功能提交 `1c8f95d` 的远端检查在安装阶段因 npm 镜像 `json5` 下载返回 HTTP 504 而失败，未进入测试。后续将锁文件中的镜像下载地址改为 npm 官方源，所有包版本、依赖关系和完整性摘要保持不变；没有把安装失败记为测试通过。

官方源重新锁定安装成功，前端 153 项通过，构建通过。随后真实浏览器以 27 条上传记录验证 26 条未解决记录的前后翻页、明确部分执行和刷新持久化；布局预览发现大量孤立节点会挤压已关联节点，已改为各连通组独立布局后排布。图谱专项 21 项通过，覆盖孤立节点保留、关联对间距、排序稳定性及原有平行/反向/自环语义；构建通过。它仍是有界子图布局，不代表生产规模或自动语义聚类。

布局修复后同一 27 条记录浏览器流程再次通过，已关联节点与箭头可分辨，28 个节点全部保留。1440/375/320px 页面无横向溢出，未捕获页面异常；隔离进程和临时数据均清理。方法、数据入口及示例图随源码提供，最新远端状态仍以对应提交的检查为准。
