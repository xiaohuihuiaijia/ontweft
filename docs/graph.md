# 图谱探索

模型图展示已发布的类型和关系定义；实例图展示授权对象与具名关系；按需开启 knowledge 扩展后，知识图展示已发布知识和固定证据引用。三种语义分开，编辑沿用各自版本合同。

默认最多载入 200 节点，可选 100/200/500；画布最多 1000 关系。截断时显示有限子图提示。图例、局部筛选和列表只覆盖本次载入范围；“全库对象搜索”单独查询服务端授权全文索引，可将结果加入当前画布，索引未就绪时明确提示结果可能不完整。

单击节点即可查看属性并进入已有对象编辑器，双击节点或按 Enter 可直接打开。双击实例关系或选择“管理来源对象的关系”会展开并定位到对应关系类型；“新增关系”创建人工关系，不原地替换所选边的目标。“删除人工关系”移除人工支持；若仍有来源或持续规则支持，关系会保留并给出提示。模型图的关系定义仍通过变更集编辑。新增、删除继续使用现有接口与权限、修订检查。对象或关系保存后重新读取已授权子图，保留当前相机、坐标和展开的列表。

选择节点强调一跳邻域，选择关系核对来源、目标、名称与方向。同对节点的平行/反向关系保持不同曲线和业务 ID；自引用使用独立原创 SVG 环线，支持鼠标、键盘和触摸。图谱只是视图，不通过拖动或布局修改事实。

相互连接的节点先独立布局，再将各组与孤立节点按有间隔的区域排布。这样大量未关联记录不会把少量已关联节点挤成重叠圆点；所有对象仍逐个保留，分组只依据当前已载入图的连通性，不推断业务类别或补造关系。

超过 40 个节点时节点列表默认收起；仍可展开并以键盘逐条选择。实例节点支持按需分页展开邻域、收起和固定。拖动只改变个人坐标；展开沿用已有 Sigma/Graphology 实例和坐标，Worker 只移动新增节点。鼠标和单指拖动都支持；四像素以内的轻微移动按点击处理，拖动不会误打开表单。画布聚焦后，方向键选择首个节点或移动选中节点，Shift 加快步长，Enter 打开，Esc 清除选择。固定节点不能被鼠标、触摸或方向键移动。个人视图保存在本浏览器，恢复时重新鉴权，不缓存业务对象内容。

默认让节点标签避让，关系名称在选中邻域后出现，也可通过工具栏“关系名称”切换显示。画布统计与类型图例仅来自当前可见数据。手机上详情排列在画布下方，保留完整编辑入口与五项主导航。

本轮界面采用森林绿导航、浅色工作区、紧凑工具栏和上下文属性面板。参考 [shadcn/ui Sidebar](https://ui.shadcn.com/docs/components/base/sidebar) 的分组与移动导航组织，以及 [React Flow 可访问性](https://reactflow.dev/learn/advanced-use/accessibility) 的方向键、Enter、Esc 操作模式。仅参考公开交互模式，没有复制其组件、Pro 示例或设计素材，没有引入 Tailwind、React Flow、Radix 或额外 UI 依赖。图标为本地原创 SVG 路径。

图形依赖为 Sigma 3.0.2、Graphology 0.26.0、@sigma/edge-curve 3.1.0；许可保留于前端第三方通知。分道规则、标签边界与自环几何是本地实现，参考 [Sigma 3 图层](https://v3.sigmajs.org/docs/advanced/layers/) 和 [坐标系统](https://v3.sigmajs.org/docs/advanced/coordinate-systems/) 的公开接口。

`node scripts/verify_graph_scale.cjs` 创建独立合成数据，记录 SQL 数、API 和交互耗时及桌面/手机截图。详见 [贡献说明](../CONTRIBUTING.md)；结果不是生产压测或 INP 指标。

`node scripts/verify_graph_workbench.cjs` 在独立临时 SQLite 与真实 Chromium 中创建 18 个合成对象、28 条关系，验证鼠标/触屏拖拽、固定及恢复、键盘与双击编辑、实际保存、关系表单定位、新增关系且旧边 ID 与目标保留、画布更新和 320/375/768/1024/1440px 布局。截图和结果位于忽略目录 `var/reports/graph-workbench/`，不是生产数据或规模验收。
