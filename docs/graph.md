# 图谱探索

模型图展示已发布的类型和关系定义；实例图展示授权对象与具名关系；知识图展示已发布知识和固定证据引用。三种语义分开，编辑沿用各自版本合同。

默认最多载入 200 节点，可选 100/200/500；单次最多 1000 关系。截断时显示有限子图提示。类型图例、文本查找和列表只覆盖本次载入范围，不能据此判断全库没有其他记录。

选择节点强调一跳邻域，选择关系核对来源、目标、名称与方向。同对节点的平行/反向关系保持不同曲线和业务 ID；自引用使用独立原创 SVG 环线，支持鼠标、键盘和触摸。图谱只是视图，不通过拖动或布局修改事实。

超过 40 个节点时节点列表默认收起；仍可展开并以键盘逐条选择。密集图需要查找、筛选、缩放和详情来阅读。尚无跨批次邻域分页或固定节点。

图形依赖为 Sigma 3.0.2、Graphology 0.26.0、@sigma/edge-curve 3.1.0；许可保留于前端第三方通知。分道规则、标签边界与自环几何是本地实现，参考 [Sigma 3 图层](https://v3.sigmajs.org/docs/advanced/layers/) 和 [坐标系统](https://v3.sigmajs.org/docs/advanced/coordinate-systems/) 的公开接口。

`node scripts/verify_graph_scale.cjs` 创建独立合成数据，记录 SQL 数、API 和交互耗时及桌面/手机截图。详见 [贡献说明](../CONTRIBUTING.md)；结果不是生产压测或 INP 指标。
