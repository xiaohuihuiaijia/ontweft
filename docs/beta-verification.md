## 规模与性能

实际测试环境为 Docker Linux，6 个可用 CPU、约 11.68 GiB 内存；应用使用受限 NOBYPASSRLS 角色和 PostgreSQL 17.11。它小于计划的 8 vCPU／32 GB 参考环境，也不是最低安装要求。

数据为 100,000 个对象、1,000,000 条关系、50 个不同用户。50 个并发客户端执行 1,000 次稳定负载 HTTP 请求：350 次唯一编码的全文检索、350 次邻域分页、300 次对象详情；首轮 50 次请求另行记录。检索和匹配索引由合成夹具预建，此项测量不代表首次接入、全量建索引、常见词大结果集或复杂多词检索的速度。

最终代码，单个 API 服务内 4 个 Uvicorn 进程、独立压测客户端的测量：

| 请求 | P50 | P95 | 结果 |
| --- | ---: | ---: | --- |
| 唯一编码全文搜索 | 0.505 s | 1.176 s | 仍超过 1 s 目标 |
| 邻域分页 | 0.312 s | 0.699 s | 本夹具达到 1 s 目标 |
| 对象详情 | 0.256 s | 0.557 s | 本夹具达到 1 s 目标 |

本轮稳定负载及首轮请求全部成功。首轮同时发起 50 次检索，P95 为 1.911 s，未藏入预热步骤。10 万对象的后台模型校验为 402 批、103.44 s；20 次顺序对象修改经真实 worker 同时传播到检索和规则关系，P95 为 0.370 s。这个传播结果不是 50 个并发写入者的压力测试。

最初检测到 RLS 下旧全文表达式扫描整租户索引表。复用派生表改为规范化词项等值索引后，实际 PostgreSQL 执行计划使用 Index Only Scan，示例计数查询执行约 0.234 ms。租户／字段权限没有放宽。早期把负载生成器与 API 放在同一 Python 进程的结果不用于最终验收。

调优前，独立客户端＋单 API 进程的三项 P95 分别为 2.563／1.380／1.169 s。改造复用已有索引表、合并重复状态及匹配字段读取，并在服务就绪前加载本地分词器；没有增加搜索服务或放宽鉴权。默认部署仍用 1 个 API 进程，测试配置为 `API_WORKERS=4`。**全文查询目标仍未全部达到，不能宣布企业 Beta 性能验收完成。**下一项性能验收需要在专用参考环境测量真实数据分布，再据瓶颈决定调整。

复现方式（先提供专用测试 PostgreSQL 的两个环境变量，不要指向生产库）：

```sh
python scripts/beta_benchmark.py --objects 100000 --relations 1000000 --users 50 --workers 4
```

工具创建并删除随机命名的独立测试数据库；客户端与 API 分属不同进程。原始结果默认位于 `var/beta-benchmark.json`。

## 部署与恢复

实际 Linux Compose 验证已通过：production 配置、Secure Cookie、受限数据库角色、异人审批、真实采集 worker、健康检查、任务指标、独立空库／空卷恢复及原始文件字节一致性。

小夹具测得备份 3.17 s、恢复到可登录并读取对象／原件 22.31 s。随后实际完成 100,000 对象／1,000,000 关系的隔离恢复：备份 **9.24 s**，恢复到可登录并核对对象、关系总量和原件 **61.94 s**。附件只有一份实际上传 CSV 及其规范化表；这个结果不能推断大体积文档库或真实灾难条件下的恢复时间。

```sh
docker build -t ontweft:beta-test .
python scripts/verify_deployment.py
python scripts/verify_deployment.py --scale
```

RPO 仍取决于部署者实际执行的备份频率和完成时间；当前工具没有自动备份调度，也未据一次恢复声称达到生产 RPO。

## 尚未宣称通过

- 8 vCPU／32 GB 专用参考机上的正式性能验收、长时间持续负载、并发写入传播与不同数据分布。
- 大体积文档／附件集的恢复和真实灾难条件；仅数据库合成规模不能替代它们。
- 真实飞书员工授权、外发和复杂 OCR；需要分别配置和验收。
- 完整 OWL／SHACL、通用推理、向量及自然语言查询。这些仍按实际用例后续推进，核心不依赖它们。
- 商标清查、完整安全审计及所有第三方二进制／模型包的再分发验收。

## 图谱工作台交互更新

前端沿用五个主入口，恢复森林绿品牌导航并收紧工具栏与属性面板。保留 Sigma/Graphology 与现有编辑器；本次没有新增运行时依赖。新增鼠标与单指拖动、方向键移动、双击打开、关系表单定位，以及保存后保留相机与坐标的授权子图刷新。关系名称默认按选中范围显示，也可显式开启。
