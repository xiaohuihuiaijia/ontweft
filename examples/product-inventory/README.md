# 产品、库存与适用条件

`sample.json` 是本机体验和展示截图共用的一份版本化合成样例，包含 20 个对象、24 条关系及其本体定义。`source.md` 是可在产品中回查的原始说明，所有内容均为人工编排的虚构演示数据。

完成三个任务：查看 SYN-04 的属性及库存；查看“室内传感采集”关系的 24 V 条件；打开固定来源版本，修改条件并查看历史。它演示真实操作与证据流程，不衡量模型抽取准确率。

从仓库根目录运行 `uv run --locked --no-dev python scripts/start_local_demo.py experience`（先按源码安装步骤准备环境），或使用首页提供的预构建体验镜像。加载器通过现有 API 在独立的“产品与库存 · 合成样例”项目中创建数据；普通启动不加载。完成后重启不会重置修改、重新补建已删除对象或再次调用模型。首次加载中断会保留进度，再次使用同一体验目录可继续；需要重新体验时使用新的空数据目录或新的命名卷，不删除未知数据。

样例模型、实例与关系仍遵循应用的校验、审批、权限和历史机制。体验采用现有单人审批模式，团队部署的异人审批保持不变。
